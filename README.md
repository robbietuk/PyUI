# PyUI

A basic starter Python project designed to work well with `uv`.

## Quick start

1. Create a virtual environment and install dependencies:
   ```bash
   uv sync --dev
   ```
2. Run the app:
   ```bash
   uv run pyui
   ```
3. Run tests:
   ```bash
   uv run pytest
   ```
4. Run static type checking:
   ```bash
   uv run mypy src
   ```
5. Install the pre-commit hook:
   ```bash
   uv run pre-commit install
   ```
